# DD Handmade Studio — Phase 1

A zero-cost, single-page prototype for selling paintings and crochet products.

## Run locally
Double-click `index.html` or open it in Chrome/Safari.

## Before publishing
Open `index.html` and change:
`const WHATSAPP_NUMBER = "919999999999";`

Use your WhatsApp number in international format without `+` or spaces.

## Replace mock products
Edit the `products` array near the bottom of `index.html`.
Later, real product photos can replace the emoji/gradient placeholders.

## Free publishing
1. Create a GitHub account.
2. Create a public repository, for example `dd-handmade-studio`.
3. Upload `index.html`.
4. Repository Settings → Pages → Deploy from branch → `main` / root.
5. GitHub will provide a free `github.io` website address.

No paid hosting or domain is required for Phase 1.
